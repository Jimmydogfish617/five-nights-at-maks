* Five Nights at Maks — Browser demo

This repository now contains a playable browser demo. Open index.html in a modern browser (Chrome/Edge/Firefox) and press "Start Night" to play.

Controls
- Click CAM buttons or press number keys 1-4 to switch cameras.
- Click "Toggle Monitor" or press M to turn the monitor on/off. Camera use drains power while on.

Objective
- Survive the night (60 seconds per night). Survive three nights to win.

Notes
- This is a small fan-style demo made for playing locally or via GitHub Pages. No external assets are required.
